# 粵語學習中心 · Cantonese Learning Center

粵語零基礎 40 天學習計劃 —— 由聲調到開口講。

## 在線使用

👉 **https://jgcindy.github.io/cantonese/**

## 內容

- **40 天路線圖**：四階段遞進，每天有明確通關標準，打卡進度存在本機
- **音系地基**：九聲六調、粵拼、入聲、變調，附聲調最小對立對與發音要領
- **14 個場景會話**：120+ 句，每句帶粵拼與普通話對照，可逐句聽讀
- **專注練一句**：聽 → 慢速 → 循環跟讀 → 遮住自說 → 說對了，五步閉環，逐句計分
- **錄音回放 + 音高曲線**：錄下自己的發音，與示範的聲調輪廓同圖對比
- **主題詞彙庫**：12 大類 200+ 詞
- **朗讀跟讀訓練**：四級遞進，含變調與語流標注
- **港劇 / 粵語歌學習**：分難度推薦，附搜索關鍵詞
- **間隔重複**：按 1/3/7/14/30 天安排複習
- **聽辨自測**：聽音選字、聽音辨調

## 使用提示

- **錄音功能需要 HTTPS 或 localhost**：這是瀏覽器安全策略，`file://` 雙擊打開時麥克風一律不可用。用上面的在線地址即可正常錄音。
- **粵語發音**：依賴瀏覽器內置語音合成。桌面版 Edge / Chrome 自帶「粵語（香港）」，手機瀏覽器多數沒有，可能退化成普通話讀法。
- 進度、練習記錄、錄音全部只存在你自己的瀏覽器，不上傳任何伺服器。

## 技術

單文件 HTML，無構建、無依賴、無後端。語音用瀏覽器原生 `speechSynthesis`，音高分析用 `AudioContext` + 自相關法（`detectF0`）。
